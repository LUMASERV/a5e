# Code of Conduct

A5E follows the [Contributor Covenant](https://www.contributor-covenant.org/version/2/1/code_of_conduct.html),
version 2.1. Read the full text in the repo:
[`CODE_OF_CONDUCT.md`](https://github.com/LUMASERV/a5e/blob/main/CODE_OF_CONDUCT.md).

Instances of unacceptable behavior may be reported via the contacts listed in
[Security](/guide/security), or by opening a GitHub issue if the matter isn't sensitive.
